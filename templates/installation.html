GUIDE POUR LES EMPLOYÉS

Installer et utiliser l’Assistant Caisse

L’application permet de chercher un code par nom, par photo ou par dictée. Une connexion Internet est nécessaire.

iPhone ou iPad

  1. Ouvre assistant-caisse-iga.onrender.com dans Safari.
  2. Touche le bouton Partager.
  3. Choisis Sur l’écran d’accueil, puis Ajouter.
  4. Ouvre l’icône Assistant Caisse et entre le code du magasin.

Android

  1. Ouvre assistant-caisse-iga.onrender.com dans Chrome.
  2. Ouvre le menu ⋮.
  3. Choisis Installer l’application ou Ajouter à l’écran d’accueil.
  4. Ouvre l’icône Assistant Caisse et entre le code du magasin.

Utilisation

  • Clavier : écris le nom ou le code du produit.
  • Photo : cadre un seul produit, assez près, avec un bon éclairage. Confirme toujours la variété et la mention bio.
  • Parler : dis seulement le nom du produit. Si la dictée ne fonctionne pas, utilise le clavier.
  • Résultat : vérifie le nom et le format avant d’utiliser le code affiché.

Si ça ne fonctionne pas

  • Vérifie le Wi-Fi ou les données cellulaires.
  • Ferme complètement l’application et rouvre-la.
  • Autorise la caméra ou le microphone lorsque le téléphone le demande.
  • Si le produit n’est pas reconnu, cherche son nom et avise un responsable.

Important : ne partage pas le code du magasin à l’extérieur de l’équipe. Les photos analysées restent sur le téléphone; l’application envoie seulement la recherche du produit à la base centrale.
