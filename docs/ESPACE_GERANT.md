# Espace gérant

Depuis la caisse, choisir **Espace gérant**, puis entrer le **code admin partagé** du magasin. Aucun compte personnel à créer. Le code existant reste valable.

- **Ajouter** : choisir « Ajouter un produit », inscrire le nom et le code, choisir une photo sur l’appareil, puis « Enregistrer ».
- **Modifier** : rechercher le nom ou le code, choisir « Modifier », faire les changements, puis « Enregistrer ».
- **Photo** : la photo choisie apparaît avant l’enregistrement. « Enlever la photo » retire l’image de la fiche lors de l’enregistrement. Une photo refusée ne remplace pas la précédente.
- **Retirer** : ouvrir la fiche, choisir « Retirer », puis confirmer. Pour masquer temporairement le produit, décocher « Visible à la caisse » et enregistrer.
- **Procédures** : ouvrir l’onglet « Procédures » pour ajouter ou modifier les réponses officielles.

Les catégories, autres noms et précisions se trouvent dans « Plus de détails (facultatif) ». Les changements sont partagés avec les tablettes connectées.

L’accès utilise la configuration ADMIN_PASSWORD ou ADMIN_PASSWORD_HASH déjà en place, sans nouveau code de superviseur ni changement de base de données. L’accès des tablettes à la caisse reste inchangé.
